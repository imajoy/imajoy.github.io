For Autodesk Maya 2023 and newer on Windows.

Thirteen tools in one Maya menu.

Each tool does one job well, and every one can be given its own hotkey. The Ajoy Tools menu and shelf appear in Maya after you install.

Export

  • FBX Exporter

    Export rig assets, deformation joints and cameras by shot.

  • Alembic Exporter

    Export geometry and cameras with UVs, visibility and face sets.

  • Playblast

    Capture camera previews with resolution presets and audio.

  • Audio Exporter

    Extract WAV audio from video shots and optionally import it into Maya.

Animation

  • IK / FK Snap

    Match arm IK and FK controls with saved rig presets.

  • Advanced IK FK Switch

    Switch between IK and FK controls without losing the pose.

  • Rebake IK Space

    Move an IK control into a new space (follow a parent, finalize, or bake to world) and keep its animation.

  • Multi Swapper

    Moves your animation onto locators and back, keying only the frames you already keyed.

Rigging

  • Rivet

    Attach a locator to a polygon or NURBS surface.

Scene

  • UDIM Preview

    Generate texture tile previews at your chosen quality.

  • Layer Prefix Remover

    Remove or replace a prefix on display and legacy render layers.

  • Hotkey Manager

    Inspect, export, import and apply custom Maya hotkeys.

  • Revert to Last Saved

    Reload the last saved scene with a backup of unsaved work.

From download to menu in four steps.

The setup file contains no tools. It only signs you in, and downloads and installs Ajoy Tools after your code is accepted.

  1. Download the setup file

    It is free for anyone to download.

  2. Drag it into the Maya viewport

    Close other Maya sessions first.

  3. Choose Online or Offline, enter your code

    The code is checked online before anything is installed.

  4. Click Install

    Maya restarts by itself and the Ajoy Tools menu and shelf are ready.

Questions studios ask.

Which versions of Maya does it support?

Autodesk Maya 2023 and newer, on Windows.

What is the difference between Online and Offline?

Online checks your subscription each time Maya starts and always runs the newest version. Offline works without an internet connection once installed, and you choose when to update from the Ajoy Tools menu.

What happens if I stop paying?

Access is tied to an active subscription. When it ends, your code is turned off and the tools stop working. See the license for the full terms.

Can I assign hotkeys to the tools?

Yes. Right-click any tool in the Ajoy Tools menu or on the shelf and choose Assign Hotkey. Maya tells you if the combination is already in use.

What else do I need installed?

The fbxmaya plug-in for FBX export and AbcExport for Alembic export. The Audio Exporter also needs FFmpeg, which is not bundled.

How do I remove it?

Choose Ajoy Tools, then Uninstall, and confirm. Your settings, presets and exported files are kept.

Is the setup file safe to share?

Yes, it contains no tools and no secrets. It cannot install anything without a valid code.
