BEFORE YOU START

What you need

A Maya hotkey set and, for importing, a saved hotkey file.

GOOD TO KNOW

A detail worth keeping in mind.

Applying changes your active hotkeys. Revert restores the earlier key setup but does not delete newly added commands.
