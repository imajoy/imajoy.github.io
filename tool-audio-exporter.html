AUDIO EXPORTER / FFMPEG SETUP

From download
to your first export.

Get FFmpeg, put its files in place, and connect it to Windows. Follow this walkthrough from start to finish, or choose a numbered step to review its illustration.

  1. Get the shared FFmpeg.rar archive for Windows, or choose a Windows build from the official FFmpeg site.

    Download FFmpeg.rar

    Hosted on Google Drive. Other builds: official FFmpeg downloads.

  2. Extract the archive and place its folder at C:\FFmpeg. The applications and DLLs should be directly inside this folder.

  3. Check for ffmpeg.exe, ffplay.exe, ffprobe.exe and their matching DLLs, as illustrated. Windows may hide the .exe extension.

  4. Open Start and search for Edit the system environment variables. Open the matching Control Panel result.

  5. In the Advanced tab of System Properties, choose Environment Variables… near the bottom.

  6. In the upper User variables section, select Path and choose Edit….

  7. Choose New and enter C:\FFmpeg. This should be the folder containing ffmpeg.exe. Keep the other Path entries.

  8. Choose OK in the Path editor, OK in Environment Variables, then OK in System Properties.

  9. Close and reopen Terminal. In File Explorer, open C:, right-click an empty area and choose Open in Terminal. Run ffmpeg -version. A version line confirms it is available. Restart Maya before opening Audio Exporter.

Different folder? Use its actual location.

If your build keeps ffmpeg.exe in C:\FFmpeg\bin, add that folder instead. If Windows says the command is not recognized, check the Path entry and reopen Terminal. You can also browse to ffmpeg.exe in Audio Exporter.
