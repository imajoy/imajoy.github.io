BEFORE YOU START

What you need

Wrapline FBX Exporter is an AJOY script that uses Maya’s built-in fbxmaya plug-in. The Maya plug-in needs no separate download. If it is not loaded, open Windows → Settings/Preferences → Plug-in Manager, find fbxmaya.mll, and check Loaded. Enable Auto load to keep it available next time Maya starts.
