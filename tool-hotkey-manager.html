Hotkey Manager

Inspect, export, import and apply custom Maya hotkeys.

Get access Download setup
InspectExportImport

What it does

  • Shows your custom Maya hotkeys
  • Exports them to a file and imports them again
  • Applies them, so a new computer feels like your old one

What you need

  • Autodesk Maya 2023 or newer, on Windows
  • An active Ajoy Tools license

Where to find it

  • Open it from the Ajoy Tools menu in Maya, or from the Ajoy Tools shelf
  • Right-click it and choose Assign Hotkey to give it its own shortcut
