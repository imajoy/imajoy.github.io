IK / FK Snap

Match an arm from IK to FK or FK to IK without a pose jump. Set up the character once, save a rig preset and reuse that mapping on the next shot.

BEFORE YOU START

What you need

An arm rig with the five required controls and an appropriate elbow axis.

GOOD TO KNOW

A detail worth keeping in mind.

Snap matches the pose only. It does not set keys or change the rig’s IK/FK switch.
